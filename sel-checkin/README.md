# SEL 情緒簽到（自我覺察）

全校以班級為單位，學生在班級座號圖卡點自己，再依年級選情緒（低年級 4 種、中年級 8 種、高年級 12 種，堆疊），可寫留言，簽到後顯示全校共同的辰光五手勢，老師在看板即時看到全班情緒並記錄處遇。

| 檔案 | 用途 |
|---|---|
| `index.html` | 學生簽到頁（每班一個 QR：`.../sel-checkin/?c=3甲` = 三年甲班） |
| `teacher.html` | 教師看板：**老師只看得到自己的班**（每班一組密碼） |
| `principal.html` | 校長總控台：看全校各班與**學生姓名**、優先關心名單、匯出 CSV |
| `faces.js` | 12 種情緒的向量臉譜、柔和配色與一句話描述（學生頁與看板共用，改配色／描述只改這支） |
| `stats.js` | 情緒趨勢統計畫面（教師看板與校長總控台共用） |
| `Code.gs` | Google Apps Script 後端，資料存進你的 Google 試算表 |
| `RosterSeed.gs` | **不在倉庫內**（含學生姓名）。一次性匯入名單到試算表的 Roster 分頁，執行完即刪 |

## 部署（約 5 分鐘）
1. 新增一份 Google 試算表 → 擴充功能 → Apps Script → 貼上 `Code.gs`。
2. 專案設定 → 指令碼屬性 → 新增 `PRINCIPAL_PASSCODE`（校長密碼）。老師密碼不在這裡設，在試算表 `Teachers` 分頁（見下）。
3. 部署 → 新增部署 → 網頁應用程式 → 執行身分「我」、存取「任何人」→ 複製網址。
4. 把網址貼到 `config.js` 的 `SEL_GAS_URL`（三個頁面共用），推上 GitHub Pages。
5. 另開一個 Apps Script 檔，貼上 `RosterSeed.gs` → 執行 `seedRoster` 一次 → 刪除該檔。名單只存在你的試算表（Roster 分頁），之後增減學生可直接改分頁，或用看板「📋 班級名單」。

未設定 `GAS_URL` 時為展示模式，資料只存在該裝置，方便試玩。

## 自我圖式（學生自選圖案）
學生點自己的座號後，可從 48 個圖案（動物、食物、自然、運動、愛心）選一個代表自己；之後班級圖卡、老師看板、校長總控台都會在座號旁顯示。圖案存在 Roster 分頁的「圖案」欄；可點「🎨 換圖案」更換，老師重存名單時會保留。圖案清單在 `index.html` 的 `AVATARS`。
注意：學生頁沒有登入，同班同學理論上可以幫別人換圖案，屬低風險的小玩笑；若發生，老師可在試算表清空該列的「圖案」。

## 早上心情 ／ 放學心情，與當天心情變化
- **不看時間，看第幾次**：學生當天**第一次送出＝Check-in（早上心情）**，**第二次送出＝Check-out（放學心情）**，由後端依當天紀錄自動判定（前端傳的時段不採用），學生不需要切換。
- 學生點自己的號碼後，畫面會預告這次是「☀️ 今天第一次：早上心情 Check-in」或「🌇 今天第二次：放學心情 Check-out」；圖卡顯示「✓ 已Check-in」「✓✓ 今日完成」。第三次以後視為「更正放學心情」（統計取最新一筆）。
- 試算表 Checkins 新增「時段」欄（am／pm）。**舊試算表不用手動改**，第一次簽到時後端會自動補上標題；沒有時段的舊資料才會依簽到時間推算（12 點前為早上）。
- 同一位學生同一時段若有多筆（例如更正）只取最新一筆。
- **當天心情變化**（同一天早上、放學都有簽到者）分四類：**好轉**＝非綠→綠、**持平**＝顏色不變、**轉換**＝非綠→另一種非綠、**轉差**＝綠→非綠。
- 老師看板「今日」：顯示每位學生「早上→放學」的臉與變化標記，並有「今日心情變化」摘要（轉差的排最前面）。校長總控台表格也有早上／放學／變化三欄。
- 統計（短／中／長期）新增「當天心情變化」：好轉／持平／轉換／轉差的人數與比例、逐日（逐週）變化圖、早上與放學的情緒分布、各班早／放學簽到率與好轉／轉差人次。持續關注名單也會納入「當天由綠轉差 3 次以上」。
- 為保護隱私，學生頁**不會**顯示任何人（包含自己）另一時段的心情；變化只有老師與校長看得到。
- 匯出 CSV 改為：早上顏色／情緒、放學顏色／情緒、當天變化。
- 即時通知的「一天一次」改為「同一時段一次」（早上、放學各最多一封）。

## 即時通知導師（Email）
學生一按送出，導師幾秒內就會收到 Email（手機 Gmail 會跳通知）：
- **紅色**一律通知；**藍色／黃色**只有學生寫了留言才通知；同一位學生一天只通知一次。
- 收件人：Teachers 分頁該班的「信箱」欄（請用學校 Google 信箱）。可在「專案設定 → 指令碼屬性」另設 `PRINCIPAL_EMAIL`（校長副本）、`DASHBOARD_URL`（信裡的看板連結）。
- 信裡只有班級、座號、姓名、情緒，**不含留言內容**；詳細內容要登入看板。
- 第一次使用：在 Apps Script 編輯器選 `testAlert` 執行一次，授權寄信權限並確認收得到測試信，再重新部署新版本。
- 寄信失敗或額度用完都不會影響學生簽到。

## 情緒統計（短／中／長期）
兩個看板都有「📈 趨勢統計」分頁，可切換：**短期 7 天、中期 30 天、長期 180 天（約一學期）**。
- 內容：簽到人次、負向情緒（紅＋藍＋黃）占比與前一期比較、情緒走勢堆疊圖（30 天內逐日、更長逐週）、情緒排行、各班比較與參與率（校長）、**持續關注學生**。
- 持續關注條件（任一）：連續 3 次以上非綠色、簽到 5 次以上且負向占 60% 以上、紅色 3 次以上。門檻在 `Code.gs` 的 `stats_()`。
- 每位學生每天只取最新一筆；老師只能統計自己的班，校長可選「全校」或單一班級。
- 期間長度由網址參數 `days` 決定（1–400），按鈕在 `stats.js` 的 `RANGES`。

## 權限與隱私
- **學生頁只顯示座號，不顯示姓名**；後端依座號從 Roster 補上姓名。
- **老師**：用 `Teachers` 分頁的班級密碼登入，後端只回傳該班資料（即使改網址也看不到別班）。一位老師帶多班，就在該分頁填多列、同一組密碼。
- **校長**：用 `PRINCIPAL_PASSCODE` 登入 `principal.html`，可看全校含姓名。
- 試算表本身請只分享給校長；`Teachers` 分頁內有各班密碼。

## 需要依學校調整
- `EMOTIONS`（index.html）：12 種情緒，`tier` 1/2/3 對應低/中/高年級（堆疊），各歸屬紅藍黃綠一色；`COLORS`：4 色的緩和策略；
- 只在週一至五開放（`SCHOOL_DAYS`），放假日填 `HOLIDAYS`；`SIGNALS`：辰光五手勢的圖與說明。
- 看板的「優先關心」：紅色，或藍色且有留言，且尚未記錄處遇。

## 隱私提醒
試算表含學生個資，只分享給授課教師；密碼為全校共用，建議定期更換。
